## ⚙️ Universal Setup & Installation

Want to test these tools locally? Follow these global steps to get the environment running on your machine.

<details>
<summary><b>1️⃣ Prerequisites (Click to expand)</b></summary>
<br>
Before running any of the scripts, ensure you have the following installed:

*   **Git:** For version control and cloning.
*   **Python 3.8+**: The core language for the backend tools.
*   **Npcap (Windows)** or **libpcap (Linux)**: Required for the Task 1 Packet Analyzer.
</details>

<details>
<summary><b>2️⃣ Clone the Repository</b></summary>

</details>

<details>

</details>
